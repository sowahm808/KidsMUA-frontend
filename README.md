# KidsMUA Frontend
Angular 20 standalone frontend for **Mind Unlocking Academy – Christian Edition**, a 98-day Christian literacy and encouragement campaign.

## Run locally
```bash
npm ci
npm start
```

## Scripts
`npm run typecheck`, `npm run lint`, `npm run test`, `npm run build:production`, `npm run e2e:smoke`.

## Backend endpoints required
Auth (`/api/v1/auth/*`), students, learning sessions, onboarding, consent, curriculum, assessments, progress, stars, badges, rewards, encouragement, notifications, certificates, reports, safeguarding, files, and admin endpoints.
